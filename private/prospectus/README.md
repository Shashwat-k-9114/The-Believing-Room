# Sponsorship prospectus

Place the FINAL, reviewed and externally approved PDF here as `the-believing-room-sponsorship.pdf`.

It is deliberately not in `public/`: it is served by `/sponsors/prospectus` only while the organiser has ticked
"Prospectus reviewed and externally approved" in the admin (Settings). Until both are true the site offers
"Request the prospectus" instead and the route returns 404.

Never place a draft, template, contract or any document containing internal financial information here.
